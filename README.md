# Rain_prediction-deployment

Вебзастосунок для прогнозування ймовірності дощу наступного дня на основі погодних даних Австралії.

### Про проєкт
- **Модель:** Random Forest Classifier
- **Точність:** близько 85%
- **Інтерфейс:** Streamlit

### Можливості
- Введення погодних показників
- Автоматична обробка даних
- Прогнозування ймовірності дощу у відсотках

### Технології
Python, Scikit-learn, Pandas, Streamlit, Joblib.

### Посилання на застосунок
Буде додано після розгортання.
